# WECCIT-PLAST (mobile + PC, données de démonstration)
Lancer : VS Code → Live Server → clic droit sur `index.html` → Open with Live Server (internet requis pour Tailwind et la police).
- `js/photos.js` : associe chaque écran à une photo. Ajoute tes photos dans `assets/photos/`, déclare-les dans `pool` (utilisées sur tous les écrans non listés) ou dans `screens`.
- `js/data.js` : `tarifKg` (null = le tarif est saisi dans l’écran « Calcul du montant »), `whatsapp` (ex. `221770000000`).
- PC ≥ 900 px : menu latéral + écrans en deux colonnes photo/contenu. Mobile : barre d’onglets en bas.
- Vérifie les droits d’utilisation des photos issues du web avant publication.
